## 🚀 Problem Statement
**EdTech & Skill Development**: Build solutions that transform how people learn and develop skills. This track encourages ideas that make education more engaging, accessible, and effective for learners of all backgrounds.

Traditional education often suffers from passive content consumption, fragmented curricula, and a lack of real-time cognitive feedback. **NeuroLearn** solves this by creating an **Agentic Educational OS** that adapts to the learner's specific career goals and mental states in real-time.

---

## ✨ Key Features

### 1. Agentic Curriculum Orchestrator
- **Dynamic Learning Paths**: Automatically generates a custom 10-node journey for any domain (Game Dev, Software Engineering, AI, etc.) based on user onboarding.
- **Neural Synapse Graph**: A D3.js powered **Knowledge Graph** that visualizes the curriculum as a connected web of neural nodes.

### 2. Cognitive Fusion Dashboard
- **Real-time Biometrics**: Tracks typing patterns, voice prosody, and answer quality to detect "Flow State," "Confusion," or "Fatigue."
- **Adaptive Recommendations**: AI suggests breaks or "Burst Mode" based on current cognitive load.

### 3. Adaptive Skill Labs (Simulations)
- **Code Lab**: Domain-specific IDE with AI-generated challenges and neural code reviews.
- **Communication Lab**: Voice-based interview simulator with sentiment and STAR-method analysis.
- **Data & Cyber Labs**: Practical simulations tailored to the user's specific career track.

### 4. Neural Passport & Mastery Map
- **Cognitive Profile**: A premium dashboard showing growth in **Creativity, Performance, Potential, Skill, and Adaptability**.
- **Neural Mastery Map**: A glowing, synapse-style visualization of core cognitive attributes.

---

## 🛠️ Technology Stack
- **Frontend**: Next.js 15+, TailwindCSS, Framer Motion, D3.js, Lucide Icons.
- **Backend**: FastAPI (Python), OpenRouter (LLM Orchestration), Supabase (Auth & Database).
- **AI Models**: Llama 3, Claude 3.5 Sonnet, and Gemini via OpenRouter.

---

## 🏁 Getting Started

### 1. Backend Setup
```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### 2. Frontend Setup
```bash
npm install
npm run dev
```
